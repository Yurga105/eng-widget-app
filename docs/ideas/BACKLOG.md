## Карточки идей

### B-001: Шеринг карточки дня картинкой *(пример оформления — удалить/заменить первой реальной идеей)*

- **Дата:** 2026-10-02 · **Категория:** рост · **Статус:** 💡 пример · **Эффект:** средн · **Затраты:** низк
- **Конфликт с PLAN.md §1:** нет — рендер картинки локально + системный share intent, офлайн, прав не добавляет
- **Проблема / возможность:** приложение не имеет вирусного цикла: пользователю нечем поделиться в мессенджерах/соцсетях, каждое слово дня — упущенный повод показать приложение друзьям.
- **Суть:** кнопка «поделиться» в карточке рендерит картинку (слово, транскрипция, перевод, бренд) и отдаёт её в системный share sheet.
- **Ожидаемый эффект:** органические установки, +N% за счёт шеринга (N уточнить на триаже).
- **Заметки / открытые вопросы:** нужен пакет рендера в image (например `repaint_boundary` → PNG, без новых тяжёлых зависимостей); локализация текста кнопки en/ru/id; на виджете кнопки не будет (RemoteViews).

### B-002: Избранное — сохранить слово дня и вернуться к нему

- **Дата:** 2026-10-02 · **Категория:** удержание · **Статус:** 💡 новая · **Эффект:** средн · **Затраты:** средн
- **Конфликт с PLAN.md §1:** нет — полностью офлайн (локальное хранение id записей), новых прав и сети не добавляет
- **Юзер-история:** «Я как пользователь хочу сохранять понравившееся слово дня себе в избранное и просматривать его в любой момент»
- **Проблема / возможность:** слово дня живёт один календарный день — понравившееся слово назавтра уже не открыть; приложение ежедневно создаёт ценность и ежедневно её теряет, причины вернуться в приложение нет.
- **Суть:** кнопка «в избранное» (звёздочка/сердечко) в карточке слова + список избранного с просмотром полной карточки любого сохранённого слова.
- **Ожидаемый эффект:** удержание — возвращаемость (D1/D7 retention) и глубина использования; любимые слова = личная коллекция = привычка открывать приложение.
- **Заметки / открытые вопросы:**
  - хранение: список id в SharedPreferences (контракт виджета §6 не трогаем) или JSON-файл в documents (паттерн word_images этапа 12);
  - UI: в v1.0 один экран — избранное потребует второго экрана (список → карточка); войти: иконка в карточке + вход в список;
  - виджет не затрагиваем: кнопок на RemoteViews нет (решение §1), избранным пользуемся только в приложении;
  - сортировка (дата добавления/алфавит) и поиск — на триаже, в v1 можно без них;
  - локализация ARB en/ru/id — по процессу этапа 10.
