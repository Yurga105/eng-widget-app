# eng_widget_app — «Слово дня» (Word of Day)

> Мини-приложение Flutter (Android + iOS) с нативным виджетом Android для домашнего экрана (4×2).
> Полностью **офлайн**: без сети, подписок и внешних API — источник данных локальный JSON-словарь.

Каждый календарный день — новое английское слово, идиома или фразовый глагол уровня B1–B2: транскрипция IPA, перевод, пример и озвучка системным TTS-движком.

## Возможности

- **Виджет 4×2** на домашнем экране: слово, транскрипция, перевод, пример (обрезка до 2 строк); светлая/тёмная тема автоматически по системной
- **Тап по виджету** → приложение с полной карточкой слова этого дня
- **Слово дня** детерминировано формулой `seed(дата) % N` — одинаково при любом числе запусков, меняется после полуночи; год входит в seed → последовательность перемешивается ежегодно
- **Автономная смена слова**: нативный `AppWidgetProvider` (Kotlin) сам пересчитывает слово при обновлении виджета — приложение запускать не нужно (включая после перезагрузки устройства)
- **Ежедневное локальное уведомление** в 09:00 (по зоне устройства), тап → карточка слова
- **Произношение**: кнопка-динамик в карточке озвучивает слово/фразу системным TTS-движком (en-US, офлайн, без прав); повторный тап или уход в фон — стоп; нет движка/голоса — кнопки нет (мягкая деградация)
- **Локализация и единый язык приложения**: интерфейс, уведомления и нативные строки виджета — en / ru / id / de / fr / es; по умолчанию «как в системе» (неподдержанная системная локаль → английский фолбэк + мини-онбординг «Выберите язык» один раз); ручной выбор в настройках управляет сразу и интерфейсом, и переводами слов (English — интерфейс английский, переводы слов русские); бренд «Word of Day» одинаков во всех языках
- **iOS (этап 11)**: тот же продукт на iPhone/iPad (iOS 15+) — адаптивный интерфейс (Cupertino-навбар, SF-иконки, CupertinoActivityIndicator), локальные уведомления (Darwin), системный TTS; домашнего виджета на iOS в v1.0 нет (WidgetKit — v1.1, требуется Mac)
- **Фото-ассоциация (этап 12)**: своя картинка к слову дня — камера или галерея (`image_picker`, сжатие maxWidth 1600 / quality 85), хранится по `id` записи (переживает годовые повторы слова), замена и удаление прямо из карточки; на виджет не попадает
- **Избранное (этап 13)**: звезда в карточке слова — контурная/янтарная; список избранного из AppBar (свежие сверху, удаление свайпом), полная карточка сохранённого слова с озвучкой и фото-ассоциацией; хранение `documents/favorites.json` — ноль новых прав и зависимостей
- **Квиз-повторение (этап 14)**: каждые 3 дня мини-квиз из 5 вопросов «слово → перевод из 4 вариантов» (материал — избранное с добором из словаря); подсветка верно/неверно, результат со счётом и «словами на повторение»; локальное напоминание в 10:00 на +3 дня (тап → квиз); история — `documents/quiz_results.json`, ноль новых прав и зависимостей
- **Онбординг первого запуска (этап 20)**: три слайда ценности — слово дня, виджет на домашнем экране, запоминание (избранное + фото + квиз раз в 3 дня); «Пропустить» доступна всегда, а разрешение на уведомления спрашивается по кнопке «Начать» — с контекстом, а не вслепую при старте
- **Material 3**, светлая тема с зелёной палитрой (тёмной темы приложения нет; виджет следует системной теме — светлой и тёмной)

## Как это устроено

- Словарь — `assets/words_db.json` (160 записей: 50% слов + 50% идиом и фразовых глаголов; v2 — переводы слов и примеров на ru/id/de/fr/es, этап 19)
- Формула «слово дня» реализована **дважды с паритетом**: Dart (`lib/services/word_of_day_service.dart`) и Kotlin (`WordOfDayCalculator.kt`) — на общих тест-векторах
- Мост Flutter ↔ виджет: предзагрузка всей базы в `SharedPreferences` (`home_widget`), нативная сторона читает её сама
- Уведомления — `flutter_local_notifications` (+ `timezone`/`flutter_timezone` для локальной зоны), повтор переставляет нативный планировщик; тексты и имя канала локализованы
- Локализация — first-party стек `flutter_localizations` + `intl`: типобезопасные строки генерируются из ARB (`flutter gen-l10n`, `lib/l10n/`; сторонние l10n-пакеты не используются)
- Фото-ассоциации — `image_picker` + `path_provider`: файлы `documents/word_images/{id}.jpg`, по одному на запись словаря; на Android ноль новых прав (системные intents/Photo Picker)
- Избранное — `FavoriteService` + `ValueNotifier` (живая синхронизация звезды и списка без state-management-пакетов): `documents/favorites.json`, ключ — `id` записи словаря
- Никаких сетевых прав: в манифесте только `RECEIVE_BOOT_COMPLETED`, `POST_NOTIFICATIONS` и `<queries>` для видимости TTS-движка (Android 11+)

## Сборка и запуск

Требуется Flutter SDK ^3.13.4 и Android-устройство/эмулятор (Android 7.0+, minSdk 24); для iOS — macOS + Xcode (iOS 15+).

```bash
flutter pub get
flutter run
```

Тесты:

```bash
flutter test                                    # 107 тестов (unit + widget)
cd android && gradlew :app:testDebugUnitTest    # 7 JVM-тестов паритета формулы (нужен JAVA_HOME)
```

Релиз:

```bash
flutter build apk --release
```

## Структура проекта

```
lib/
  main.dart                   # MaterialApp, темы M3, l10n, WidgetsBindingObserver
  l10n/                       # ARB-переводы en/ru/id + сгенерированные классы
  models/word_entry.dart      # модель записи словаря
  services/                   # словарь, слово дня, мост виджета, уведомления, TTS, фото-ассоциации, избранное, квиз
  ui/
    screens/home_screen.dart  # экран карточки слова дня
    screens/favorites_screen.dart  # список избранного (этап 13)
    screens/word_detail_screen.dart  # карточка избранного слова (этап 13)
    screens/quiz_screen.dart  # квиз-повторение каждые 3 дня (этап 14)
    screens/settings_screen.dart  # единый язык приложения (этапы 18–19)
    screens/language_pick_screen.dart  # онбординг «Выберите язык» (правка приёмки 05.10.2026)
    screens/onboarding_screen.dart  # знакомство при первом запуске (этап 20)
    widgets/word_card.dart    # карточка + прослушивание + фото-ассоциация + звезда избранного
assets/words_db.json          # словарь (единственный источник данных; v2 — переводы на 5 языков)
tool/merge_translations.dart  # одноразовая миграция словаря до v2 + данные tool/v2_*.txt (этап 19)
android/app/src/main/kotlin/  # WordWidgetProvider, WordOfDayCalculator, BootCompletedReceiver
ios/                          # каркас iOS (Runner, Info.plist, ru/id-локализации, SPM)
docs/                         # документация проекта
test/                         # тесты Flutter
```
